# Estimating-the-Causal-Impact-of-Customer-Engagement-Interventions-on-Banking-App-Retention
Built an end-to-end causal customer-intelligence pipeline to estimate the impact of a banking-app engagement intervention on retention, combining propensity-score matching, difference-in-differences, cross-fitted AIPW heterogeneous treatment effects, customer segmentation and XGBoost churn prediction.
